# Модерация NetroxBot

Модуль модерации работает через единые кейсы. Любое наказание или важное действие получает собственный номер вида `#123`, сохраняется в истории и попадает в журнал.

## Основные команды

- `/ban user [duration] [reason]` — постоянный или временный бан;
- `/kick user [reason]` — кик;
- `/timeout user duration [reason]` — Discord timeout;
- `/mute user [duration] [reason]` — mute через отдельную роль;
- `/warn user reason` — предупреждение;
- `/unwarn case [reason]` — снять активный warn;
- `/clear amount [user] [reason]` — удалить сообщения;
- `/slowmode seconds [reason]` — изменить slowmode;
- `/lock [reason]` — закрыть текущий канал;
- `/unlock [reason]` — открыть текущий канал;
- `/history user` — последние moderation-кейсы участника;
- `/case view number` — открыть конкретный кейс;
- `/case cancel number [reason]` — отменить активное обратимое наказание;
- `/modstats [moderator] [period]` — статистика модератора.

## Длительность

Можно использовать короткий формат:

- `30s` — 30 секунд;
- `15m` — 15 минут;
- `2h` — 2 часа;
- `7d` — 7 дней;
- `2w` — 2 недели;
- `1h30m` — комбинация нескольких единиц.

Discord timeout ограничен 28 днями. Временный ban и mute могут быть дольше.

## Кейсы и временные наказания

NetroxBot сам следит за истечением временных наказаний.

После завершения срока:

- временный ban снимается;
- mute-роль удаляется;
- timeout завершается;
- кейс меняет статус на завершённый.

Если бот или Docker были перезапущены, просроченные кейсы проверяются после следующего запуска.

## Warn и автоматическое наказание

В `/settings → Безопасность и модерация → Модерация` можно настроить:

- лимит активных предупреждений;
- действие после достижения лимита;
- длительность автоматического timeout;
- канал moderation-логов;
- роль модератора;
- mute-роль;
- отправку уведомлений пользователю в ЛС.

После достижения лимита NetroxBot может автоматически выдать timeout, kick или ban. Использованные предупреждения остаются в истории, но перестают считаться активными.

## Апелляции

Участник может подать апелляцию командой:

```text
/appeal case:123 text:Причина пересмотра
```

Для warn, timeout, mute и ban NetroxBot также старается отправить пользователю ЛС с номером кейса и кнопкой **«Подать апелляцию»**. Эта кнопка остаётся полезной даже после ban, если Discord разрешил доставить личное сообщение.

Модераторы используют:

- `/appeals list` — список ожидающих апелляций;
- `/appeals accept id [note]` — принять апелляцию и автоматически отменить обратимое наказание;
- `/appeals reject id [note]` — отклонить.

## Автомодерация

Настройки находятся в `/settings → Безопасность и модерация → Автомодерация`.

Поддерживаются:

- антиспам;
- антифлуд;
- антимат;
- антикапс;
- внешние ссылки;
- Discord-приглашения;
- массовые упоминания;
- несколько ролей-исключений;
- несколько каналов-исключений;
- дополнительный пользовательский список запрещённых слов.

Для реакции можно выбрать:

- только удалить сообщение;
- удалить сообщение и выдать warn;
- удалить сообщение и выдать timeout.

Все срабатывания автомода записываются в базу и отображаются в **Moderation Center** веб-панели.

## Веб-панель

В **Moderation Center** доступны:

- последние moderation-кейсы;
- активные наказания;
- ожидающие апелляции;
- последние срабатывания автомода.

Настройки модерации и автомода одинаковые в Discord `/settings` и веб-панели: изменения сохраняются в одной базе.
