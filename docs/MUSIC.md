# Музыка в NetroxBot

Музыкальный модуль NetroxBot работает через Lavalink и рассчитан на один сервер — Mothers Fantastic.

## Источники

Из коробки доступны:

- YouTube;
- YouTube Music;
- SoundCloud;
- Bandcamp;
- Twitch;
- Vimeo;
- обычные HTTP-аудиоссылки.

Spotify и Яндекс Музыка подключаются через LavaSrc.

### Spotify

Для поиска Spotify нужны Client ID и Client Secret приложения Spotify.

В `.env`:

```env
SPOTIFY_ENABLED=true
SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=
```

Spotify в этой схеме используется как источник метаданных. Сам трек при необходимости зеркалируется через доступный аудиоисточник Lavalink.

### Яндекс Музыка

Для Яндекс Музыки нужен access token.

В `.env`:

```env
YANDEX_MUSIC_ENABLED=true
YANDEX_MUSIC_TOKEN=
```

Без токена источник остаётся выключенным. Остальная музыка продолжает работать независимо от него.

## Основные команды

- `/play` — найти трек или открыть ссылку;
- `/pause` — пауза;
- `/resume` — продолжить;
- `/skip` — skip или vote-skip;
- `/stop` — остановить плеер;
- `/queue` — очередь;
- `/nowplaying` — текущий трек;
- `/seek` — перемотка;
- `/volume` — громкость;
- `/loop` — повтор трека/очереди;
- `/shuffle` — перемешать очередь;
- `/autoplay` — автоматический подбор после конца очереди;
- `/music247` — режим 24/7;
- `/favorite` — избранное;
- `/history` — история прослушивания;
- `/playlist` — личные плейлисты.

## Контроллер

При запуске трека NetroxBot создаёт или обновляет музыкальный контроллер.

Кнопками можно:

- перейти к предыдущему треку;
- поставить на паузу/продолжить;
- пропустить трек;
- перемешать очередь;
- остановить плеер;
- добавить трек в избранное;
- переключить loop;
- открыть очередь.

Контроллер обновляется при смене трека и очереди.

## DJ и vote-skip

В настройках музыки можно назначить DJ-роль.

Если DJ-роль не задана, управление доступно участникам голосового канала. Если роль задана, расширенные действия доступны:

- участникам с DJ-ролью;
- администраторам;
- участникам с Manage Server.

Обычный пользователь всё равно может использовать `/skip`. Если включён Vote Skip, голос учитывается в текущем голосовании.

В настройках задаётся процент слушателей, необходимый для пропуска трека.

Автор текущего трека может пропустить свой трек без голосования.

## 24/7 и восстановление после рестарта

Режим 24/7 сохраняется в PostgreSQL.

NetroxBot хранит:

- голосовой канал;
- текстовый канал;
- громкость;
- loop;
- Autoplay;
- состояние 24/7;
- текущий трек;
- позицию воспроизведения;
- оставшуюся очередь.

Позиция обновляется периодически, чтобы не писать в БД на каждом событии Lavalink.

После перезапуска NetroxBot:

1. подключается к Lavalink;
2. проверяет сохранённый 24/7-плеер;
3. возвращается в сохранённый голосовой канал;
4. повторно разрешает текущий трек и очередь через музыкальные источники;
5. запускает трек;
6. пытается вернуть последнюю сохранённую позицию.

Если голосовой канал был удалён, 24/7 автоматически сбрасывается.

## Автоматический выход

Если режим 24/7 выключен и голосовой канал остаётся без людей, NetroxBot запускает таймер.

В `/settings → Музыка` можно:

- включить/выключить автоматический выход;
- задать таймер пустого канала.

Возврат участника в канал отменяет таймер.

## Плейлисты, избранное и история

Эти данные хранятся в PostgreSQL и переживают перезапуск.

Плейлист принадлежит конкретному Discord-пользователю на Mothers Fantastic.

Для сохранённых треков NetroxBot хранит не только название, но и:

- источник;
- identifier;
- URL;
- автора;
- длительность;
- обложку.

При воспроизведении сохранённого плейлиста треки повторно разрешаются через Lavalink. Это надёжнее, чем хранить старый Base64-трек Lavalink навсегда.

## Настройки

Музыкальный модуль использует общую систему настроек NetroxBot. Одни и те же параметры доступны через Discord `/settings` и веб-панель.

Можно менять:

- DJ-роль;
- громкость по умолчанию;
- основной поисковый источник;
- Autoplay;
- Vote Skip;
- процент Vote Skip;
- автоматический выход;
- таймер пустого канала;
- разрешение режима 24/7;
- максимальный размер очереди;
- плейлисты;
- избранное;
- историю.

## Архитектура источников

NetroxBot использует Lavalink 4.2.2.

YouTube работает через официальный `youtube-source`, а встроенный устаревающий YouTube source Lavalink выключен.

Spotify и Яндекс Музыка подключены через LavaSrc. SoundCloud остаётся штатным источником Lavalink.

Node-часть использует Shoukaku для соединения с Lavalink и Kazagumo для плеера и очереди.
