# NetroxBot

NetroxBot — основной бот Discord-сервера **Mothers Fantastic**.

Цель проекта простая: не собирать сервер из десятка разных ботов, а держать модерацию, музыку, экономику, профили, поддержку, автоматизацию, статистику и серверные инструменты в одном месте.

## Статус

Проект находится в активной разработке. Первая цель — собрать прочный фундамент, на котором дальше будут независимо развиваться крупные модули.

## Что планируется

- модерация, автомодерация, наказания, апелляции и статистика модераторов;
- музыка, очереди, плейлисты и музыкальная панель;
- экономика **🪙 NetCoin (NEC)**, банк, магазин, предметы, маркетплейс и аукционы;
- уровни, профиль, репутация, достижения и косметика;
- welcome/goodbye, верификация, приглашения и captcha;
- тикеты, заявки, role menu и временные голосовые комнаты;
- розыгрыши, события, голосования, напоминания и серверная статистика;
- интеграции с внешними сервисами;
- Discord-настройки через /settings и отдельная веб-панель;
- локальные AI-функции как дополнительный модуль, если позволяет железо.

## Технологии

- TypeScript;
- Node.js 24 LTS;
- discord.js;
- Fastify;
- PostgreSQL + Prisma;
- Redis;
- Next.js;
- Docker Compose;
- Lavalink для музыкального слоя;
- Ollama как необязательный локальный AI-сервис.

## Ветки

- main — стабильные версии;
- dev — текущая разработка.

Каждая стабильная версия публикуется отдельным GitHub Release с тегом.

## Важно

Секреты, токены Discord и пароли в репозиторий не добавляются. Для локального запуска используется файл .env на основе .env.example.
