# NetroxBot

**NetroxBot** — основной бот Discord-сервера **Mothers Fantastic**.

Задача проекта — держать модерацию, музыку, экономику, профили, поддержку, автоматизацию, статистику и серверные инструменты в одном месте, а не собирать сервер из десятка отдельных ботов.

> Проект сейчас находится в активной разработке. Стабильные версии выходят только через ветку `main` и публикуются отдельными GitHub Releases.

## Что будет внутри

- модерация, автомодерация, наказания, апелляции и статистика модераторов;
- музыка, очереди, плейлисты и полноценная музыкальная панель;
- экономика **🪙 NetCoin (NEC)**: кошелёк, банк, магазин, предметы, маркетплейс и аукционы;
- уровни, профиль, репутация, достижения и косметика;
- приветствия, верификация, приглашения и captcha;
- тикеты, заявки, role menu и временные голосовые комнаты;
- розыгрыши, события, голосования, напоминания и серверная статистика;
- интеграции с внешними сервисами;
- настройки через `/settings` и отдельную веб-панель;
- локальные AI-функции как дополнительный модуль, если позволяет железо.

## Стек

- TypeScript + Node.js 24 LTS;
- discord.js;
- Fastify;
- PostgreSQL + Prisma;
- Redis;
- Next.js;
- Docker Compose;
- Lavalink;
- Ollama как необязательный локальный AI-сервис.

## Ветки и релизы

- `dev` — текущая разработка;
- `main` — только стабильные версии.

Релиз создаётся тегом вида `v0.1.0`. После публикации тега GitHub Actions собирает production-образы бота, API и панели, публикует их в GitHub Container Registry и создаёт GitHub Release.

Production-сборка может сама забирать новые контейнеры после выхода релиза.

## Запуск

Подробная инструкция по установке находится в [docs/INSTALL.md](docs/INSTALL.md). Руководство по moderation-кейсам, командам и автомоду — в [docs/MODERATION.md](docs/MODERATION.md). Логи, backup и восстановление описаны в [docs/LOGS_AND_BACKUPS.md](docs/LOGS_AND_BACKUPS.md).

Для локальной разработки достаточно подготовить `.env` из `.env.example` и выполнить:

```bash
docker compose up -d --build
```

Для production-режима с автообновлением:

```bash
docker compose -f docker-compose.prod.yml up -d
```

## Безопасность

Токены Discord, OAuth-секреты, пароли и другие секреты в репозиторий не добавляются. Они задаются только через локальный файл `.env`.

Первый владелец панели создаётся из `SUPERADMIN_DISCORD_ID` во время bootstrap базы. После запуска дополнительные администраторы будут добавляться через настройки NetroxBot.
